UMUT TELSİZ WEB SİTESİ

Dosyalar:
- index.html: Ana sayfa
- style.css: Tasarım ve mobil uyumluluk
- script.js: Mobil menü ve küçük etkileşimler
- assets/: Firma logoları

GitHub'a yükleme:
1. Bu ZIP dosyasını bilgisayarında aç.
2. İçindeki index.html, style.css, script.js ve assets klasörünü GitHub deposunun ana dizinine yükle.
3. GitHub Pages ayarlarında Branch: main, Folder: /(root) seçip kaydet.
